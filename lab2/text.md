# Лабораторная № 2. Разделяемая память System V

## Как два процесса получают доступ к общим данным

У каждого процесса своё адресное пространство. Если одна программа изменит переменную у себя, другая программа этого не увидит. **Разделяемая память** позволяет обоим процессам подключить один и тот же участок памяти, который называется **сегментом**. Программы обращаются к нему через обычные указатели в C. Если один процесс запишет данные в сегмент, другой сможет прочитать их из своей памяти по тому же смещению от начала сегмента.

В коде встретятся три разных значения.

- **Ключ `key`** помогает процессам найти один и тот же сегмент. Обе программы могут независимо получить ключ через `ftok()`.
- **Идентификатор `shmid`** — целое число, которое возвращает `shmget()`. Им пользуются `shmat()` и `shmctl()`, чтобы выбрать сегмент.
- **Адрес `addr`** возвращает `shmat()`. По этому указателю процесс читает и пишет данные. У двух процессов адреса могут различаться, хотя байты в сегменте общие. Каждый процесс передаёт свой адрес в `shmdt()`.

Обычный порядок работы — получить ключ через `ftok()`, создать или найти сегмент через `shmget()`, подключить его через `shmat()`, поработать с данными и отключиться через `shmdt()`. Когда данные больше никому не нужны, сегмент удаляют через `shmctl()` или `ipcrm`.

## 1. Получаем общий ключ через `ftok()`

```c
#include <sys/ipc.h>

key_t ftok(const char *pathname, int proj_id);
```

Например, обе программы вызывают `ftok("counters.c", 'C')`. Путь должен вести к одному и тому же существующему и доступному файлу. Если путь относительный, он отсчитывается от каталога, из которого запустили программу. `ftok()` использует сведения о файле и младшие восемь бит `proj_id`. Для лабораторной удобно выбрать один ненулевой символ и использовать его в обеих программах. Не пересоздавай файл между запусками, иначе у нового файла может получиться другой ключ.

Файл нужен только для вычисления ключа. Счётчики или текст хранятся в самом сегменте. У разных пар «файл и `proj_id`» иногда получается одинаковый ключ. При ошибке `ftok()` возвращает `(key_t)-1`. [Справка `ftok(3)`](https://man7.org/linux/man-pages/man3/ftok.3.html)

## 2. Создаём или находим сегмент через `shmget()`

```c
#include <sys/shm.h>

int shmget(key_t key, size_t size, int shmflg);
```

`size` задаётся в байтах. Например, для трёх элементов `int` нужно `3 * sizeof(int)`. При поиске существующего сегмента можно указать ожидаемый минимальный размер или передать `0`, если проверять размер этим вызовом не требуется. Если запрошенный размер больше существующего, вызов завершится с `EINVAL`.

- `shmget(key, size, IPC_CREAT | 0600)` создаёт сегмент, если его ещё нет. Если сегмент уже есть и параметры подходят, вызов возвращает его `shmid`.
- `shmget(key, size, IPC_CREAT | IPC_EXCL | 0600)` требует создать новый сегмент. Если ключ уже занят, вызов возвращает `-1`, а в `errno` записывается `EEXIST`. Так можно понять, надо ли инициализировать данные.
- `shmget(key, size, 0)` ищет уже созданный сегмент. Если такого ключа нет, вызов вернёт `-1` с `ENOENT`.
- `shmget(IPC_PRIVATE, size, 0600)` создаёт новый сегмент при каждом успешном вызове. Для подключения другому процессу понадобится полученный `shmid`. Например, родитель может создать сегмент до `fork()`, и потомок унаследует значение переменной с идентификатором.

`0600` — восьмеричные права на чтение (`0400`) и запись (`0200`) для владельца. Этого достаточно, когда обе программы запущены одним пользователем. В исходном примере стоит `0666`, что разрешает чтение и запись также группе и остальным пользователям. Символ `|` объединяет права и флаги побитовым «или».

Успешный `shmget()` возвращает неотрицательный `shmid`. При `-1` можно сразу посмотреть причину в `errno` из `<errno.h>` или вывести её через `perror()`. [Справка `shmget(2)`](https://man7.org/linux/man-pages/man2/shmget.2.html)

## 3. Подключаем память и отключаемся

```c
void *shmat(int shmid, const void *shmaddr, int shmflg);
int shmdt(const void *shmaddr);
```

В `shmat(shmid, NULL, 0)` значение `NULL` поручает системе самой выбрать адрес. Третий аргумент `0` запрашивает чтение и запись, а `SHM_RDONLY` — только чтение. При успехе `shmat()` возвращает адрес начала сегмента. Ошибку проверяют сравнением с **`(void *)-1`**.

С полученным адресом можно работать как с указателем нужного типа. Для общего массива целых чисел достаточно `int *counts = addr`. Выражение `counts[0]++` изменит первый счётчик в сегменте.

После работы передай в `shmdt(addr)` исходный адрес, который вернул `shmat()`. Вызов возвращает `0` при успехе и `-1` при ошибке. Он отключает сегмент от текущего процесса. Сам сегмент обычно сохраняется даже после завершения всех программ, поэтому следующий запуск увидит прежние данные. [Справка `shmat(2)` и `shmdt(2)`](https://man7.org/linux/man-pages/man2/shmat.2.html)

## 4. Пример с двумя счётчиками запусков

В сегменте лежат три числа. `counts[0]` хранит число запусков первой программы, `counts[1]` — второй, `counts[2]` — общее число запусков. Код у программ почти одинаковый, поэтому для примера достаточно одного файла `counters.c`. При компиляции `-DPROGRAM=1` и `-DPROGRAM=2` задают номер программы.

```c
#include <errno.h>
#include <stdio.h>
#include <sys/ipc.h>
#include <sys/shm.h>

int main(void)
{
    key_t key = ftok("counters.c", 'C');
    if (key == (key_t)-1) {
        perror("ftok");
        return 1;
    }

    size_t size = 3 * sizeof(int);
    int shmid = shmget(key, size, IPC_CREAT | IPC_EXCL | 0600);
    int created = shmid != -1;

    if (!created) {
        if (errno != EEXIST) {
            perror("shmget: create");
            return 1;
        }
        shmid = shmget(key, size, 0);
        if (shmid == -1) {
            perror("shmget: find");
            return 1;
        }
    }

    void *addr = shmat(shmid, NULL, 0);
    if (addr == (void *)-1) {
        perror("shmat");
        return 1;
    }

    int *counts = addr;
    if (created) {
        counts[0] = 0;
        counts[1] = 0;
        counts[2] = 0;
    }
    counts[PROGRAM - 1]++;
    counts[2]++;
    printf("program1=%d program2=%d total=%d\n",
           counts[0], counts[1], counts[2]);

    if (shmdt(addr) == -1) {
        perror("shmdt");
        return 1;
    }
    return 0;
}
```

Из каталога с `counters.c` в Linux выполни следующие команды.

```bash
gcc -Wall -Wextra -DPROGRAM=1 counters.c -o counter1
gcc -Wall -Wextra -DPROGRAM=2 counters.c -o counter2
./counter1  # program1=1 program2=0 total=1
./counter2  # program1=1 program2=1 total=2
./counter1  # program1=2 program2=1 total=3
```

Эти результаты получатся, если начать с чистого сегмента. Первый запуск его создаёт и инициализирует счётчики, остальные продолжают счёт. Запускай программы по очереди. При одновременном `++` оба процесса могут прочитать одно старое значение и записать одно и то же новое, потеряв одно увеличение. Для параллельной работы нужна синхронизация, например семафор.

## 5. Как посмотреть и удалить сегмент

В терминале `ipcs -m` показывает сегменты памяти. Найди свой сегмент по владельцу и ключу, затем возьми число из столбца `shmid`. Например, если у твоего сегмента `shmid` равен `12345`:

```bash
ipcs -m -i 12345  # сведения об одном сегменте
ipcrm shm 12345   # удалить свой сегмент
ipcs -m          # проверить список снова
```

В списке `ipcs -m` столбец `nattch` показывает число подключений. `nattch = 0` означает, что сейчас сегмент ни у кого не подключён. Обычный `ipcs` выводит ещё семафоры и очереди сообщений. Их можно посмотреть отдельно через `ipcs -s` и `ipcs -q`. [Справка `ipcs(1)`](https://man7.org/linux/man-pages/man1/ipcs.1.html) · [Справка `ipcrm(1)`](https://man7.org/linux/man-pages/man1/ipcrm.1.html)

В программе ту же операцию выполняет `shmctl(shmid, IPC_RMID, NULL)`. `IPC_RMID` помечает сегмент на удаление. Если никто не подключён, он удалится сразу. При действующих подключениях система дождётся последнего отключения. Третий аргумент для этой команды не используется. Вызов возвращает `0` при успехе и `-1` при ошибке. Его может выполнить владелец, создатель или процесс с соответствующими привилегиями. [Справка `shmctl(2)`](https://man7.org/linux/man-pages/man2/shmctl.2.html)

## Задание к лабораторной

Напиши две программы, которые запускаются по очереди. Первая должна **скопировать собственный исходный текст C** в разделяемую память. Вторая должна прочитать его, вывести на экран и удалить сегмент.

1. **Программа записи** открывает свой `.c` файл и определяет размер текста в байтах. Если вторая программа будет выводить данные как строку, выдели в сегменте ещё один байт под `\0` и запиши его после последнего прочитанного байта. Создай сегмент через `shmget()`, подключи через `shmat()`, скопируй текст и вызови `shmdt()`. К этому моменту данные должны быть полностью записаны, а сегмент должен остаться доступным для второй программы.
2. **Программа чтения** получает тот же ключ через `ftok()` с тем же файлом и `proj_id`. Она ищет сегмент без `IPC_CREAT`, подключает его с `SHM_RDONLY` и выводит текст, например через `fputs()`, если он заканчивается на `\0`. Затем вызывает `shmdt()` и удаляет сегмент через `shmctl(shmid, IPC_RMID, NULL)`.
3. **Проверка.** Запусти запись, а затем чтение. Сравни вывод с исходным `.c` файлом и проверь через `ipcs -m`, что сегмент исчез. Если снова запустить чтение без записи, `shmget()` должен вернуть `-1` с `ENOENT`.
